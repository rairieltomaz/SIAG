# SIAG – Sistema Integrado de Aferição de Gás

Previsão de consumo de gás a partir do PDP do ONS e verificação com o totalizador do GRMS.

Acesse: https://rairieltomaz.github.io/SIAG/

No celular, abra o link e use "Adicionar à tela inicial" para instalar como app.

Versão atual: **1.4.1** (04/11/2026) – correção do token do GitHub na criação/troca de senha (usuários, senhas e Ajustes de cálculo centralizados desde a 1.3/1.4). Detalhes, regras de cálculo e histórico em [`codigo-fonte/LEIA-ME.md`](codigo-fonte/LEIA-ME.md).
